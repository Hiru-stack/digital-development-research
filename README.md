# Beyond Connectivity

**A Comparative Analysis of Digital Access, Internet Use and Digital Capability in Sri Lanka and Selected Asian Countries**

This repository contains a web-based presentation of a research study on Sri Lanka's digital development using official secondary data.

## Research Focus

The study examines whether improvements in digital connectivity are matched by improvements in:

- Internet use
- Computer literacy
- Digital literacy
- Household computer ownership

Sri Lanka is compared with selected Asian countries using internationally comparable ICT indicators.

## Data Sources

- Department of Census and Statistics, Sri Lanka — Computer Literacy Statistics Annual Bulletins
- International Telecommunication Union (ITU) — ICT DataHub indicators

## Main Comparison Countries

- Sri Lanka
- India
- Bangladesh
- Indonesia
- Malaysia

## Time Period

- Sri Lanka DCS analysis: 2014–2025
- International ITU comparison: 2014–2024

## Website

The full research presentation is contained in `index.html`.

All charts used on the website are embedded directly inside the HTML file, so separate image files are not required for GitHub Pages.

## Main Findings

- Sri Lanka's digital literacy increased much faster than computer literacy.
- Household desktop/laptop ownership remained nearly unchanged over the selected period.
- In 2024, Sri Lanka ranked relatively strongly in broadband subscriptions among the selected countries but had the lowest Internet-use rate.
- The study therefore explores a possible **connectivity–capability gap**.
